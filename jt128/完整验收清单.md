# JT128 完整验收清单（全量 · 可打印勾选）

依据《JT128 用户手册》J01-zh-260720 逐章提取。共 **9 组可勾选项 / 92 项**（★必测 57、○可选 34、⛔不测 1），另附 3 张速查表（故障索引 / 出厂默认值 / 明确不测）。
图例：★必测　○可选（有需要才测）　⛔不测（有风险或需厂家设备）　⚙= 可用本目录脚本自动验证

工具约定：
```bash
C=python3 ~/jt128/jt128_check.py --iface enp131s0     # 收包/包率/带宽/丢包/帧率/转速/温度
M=python3 ~/jt128/memwatch.py                         # 内存/CPU/FD/内核缓冲
L=~/jt128/app/LidarUtilities_Sample_JT128_3.0.5_65677db_ubuntu22.out   # 上位机（参数/信息/升级/点云）
T="sudo tcpdump -i enp131s0 -n udp port 2368"         # 抓包
```

## 4. 数据格式与协议正确性（D1~D13）⚙ 全部可用 `C --dump` + 离线校验

| # | 检查项 | 期望 / 判据 | 级 |
|---|---|---|---|
| D1 | 帧长 | 以太网帧 **1146 B**（UDP 数据 1100 B） | ★ |
| D2 | 包头标志 | `0xEE 0xFF` | ★ |
| D3 | 协议版本 | Major `0x01`、Minor `0x04` | ★ |
| D4 | 数据头 | Channel Num `0x80`(128)、Block Num `0x02`、Dis Unit `0x04`(4 mm)、Return Num 1 或 2、Flags bit[1]/bit[0]=1 | ★ |
| D5 | 数据主体结构 | Azimuth1(2)+Block1(512)+Azimuth2(2)+Block2(512)+CRC(4)=**1032** | ★ |
| D6 | 每通道字段 | Distance(u16, ×4 mm) + Reflectivity(u8, ×1%) + Confidence(u8, 仅 Flags bit5=1) | ★ |
| D7 | 数据尾 56 B 齐全 | Reserved11、Working Mode1、Return Mode1、Motor Speed2(0.1RPM)、Date6、UTC 微秒4、Factory1、UDP Seq4、IMU 温度2、Acc 单位2、Gyro 单位2、Reserved4、IMU Acc×3、IMU Gyro×3、CRC4 | ★ |
| D8 | 工厂信息 | `0x42` | ★ |
| D9 | 主体 CRC | CRC-32/**MPEG-2** 校验通过 | ○ |
| D10 | 数据尾 CRC | CRC-32 校验通过 | ○ |
| D11 | 每帧点数 | 单回波 **115 200**、双回波 **230 400**（10 Hz） | ★ |
| D12 | 角度解析 | 水平 = 数据块方位角 + 通道水平偏移；垂直查附录 A / 角度修正文件 | ○ |
| D13 | 发光时序 | 通道发光时刻**交错且非均匀**，高精度须按附录 B.4 做运动补偿（否则高速下鬼像/间隙） | ○ |

## 10. 故障对照索引（手册第 6 章）

| 现象 | 排查方向 |
|---|---|
| 电机不转 | 电源接触/电压电流、是否待机模式 |
| 转但无数据 | 网线、Destination IP、固件版本、是否出光（红外） |
| 抓包有数据但软件无数据 | 端口 2368、VLAN ID、主机防火墙、软件版本 |
| 上位机连不上雷达 | 主机 IP 同网段、VLAN、换机/重启 |
| 丢包 | 网络过载、**勿接交换机**、只接一台雷达、重新上电 |
| 点云异常/闪烁/视场残缺 | 光罩脏污、角度修正文件未导入、转速不稳、温度超限、丢包 |
| GNSS 无法锁定 | GNSS 接线、PPS 输入、GNSS Destination Port、电气规格 |

## 建议执行顺序与时间预算（约 1.5 小时）

| 阶段 | 内容 | 用时 |
|---|---|---|
| ① | H1~H10、P1~P3 上电前检查 | 15 min |
| ② | N1~N10 链路打通（`setup_host.sh` + `T` + `C`）→ 必须先过 N5/N6 | 15 min |
| ③ | D1~D13 用 `C --dump` 留一份原始包做协议核对 | 10 min |
| ④ | F1~F20 在 `L` 里逐项切，回看 `C` 数字 | 30 min |
| ⑤ | S1~S12 性能抽测（S1/S2/S5/S6 最值得做） | 15 min |
| ⑥ | R1~R6 用 `M` 盯 10 min；E1/E2 顺带 | 10 min |
| ⑦ | T1~T9 时间同步（没接 GNSS/PTP 就只做 T1） | 按需 |

**优先级**：N5/N6（有数据且不丢）→ F12（待机）→ F8/F9（回波模式）→ F5（FOV）→ F10（转速）→ R1/R4（资源）→ S1/S2（准度）。这几项过了，基本可以判定"功能完好"。
